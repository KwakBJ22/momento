첫 화면(스크롤 없이): 초대 한 줄 → 표지 카드(사진+제목+참여 수+모토를 한 덩어리로) → 참여자명 입력 → 참여 버튼. 카카오 버튼은 그 아래. 배경 #fdf7f5 위 흰 카드라 그림자 없이 색차만으로 책처럼 떠 보인다.

참여하기 화면 — 구현 메모

이 화면을 보는 사람은 서비스를 모르고, 찾아온 게 아니라 불려 온 사람이다. 그래서 서비스 소개가 아니라 초대한 사람의 이름이 첫 줄이다. 목표 한 문장: “이건 광고가 아니라 나한테 온 초대구나”.

확정 문구

  • 초대: {초대한 사람}님이 함께 만들자고 초대했어요 — 24px/800/1.4, 두 줄. 이름은 본문과 같은 검정 (빨간 이름을 쓰지 않는다)
  • 모토: 각자의 사진을 모아 하나의 앨범으로 남겨요.
  • 참여 수: 사진 N장 · 함께한 사람 N명
  • 입력 라벨 참여자명 / placeholder “앨범에서 이 이름으로 불려요”
  • 계정 안내의 ‘우리앨범’은 로고 락업으로 렌더 (우리 #1a1f2b + 앨범 #ff6b6b, 800)

버튼 위계 (색으로 주지 않는다)

카카오 노랑은 #b34a46보다 밝아 색만으로는 오히려 더 튄다. 네 가지로 위계를 준다 — ① 참여 버튼은 입력창에 바로 붙고 카카오는 구분선 뒤로 떨어진다 ② 높이 56 vs 52 ③ 18px/800 vs 17px/600 ④ 카카오 앞에는 설명 두 줄이 먼저 온다(읽고 나서 누르는 버튼). 첫 화면에 카카오를 넣지 않은 것도 위계다 — 숨긴 게 아니라 순서를 준 것.

없애는 것

  • 관계 (선택) 칩 5개 — 초대한 사람이 이미 아는 것을 다시 묻는 셈
  • ‘기억’이라는 말 — 이 서비스의 말은 한마디 하나
  • 검은색 버튼 — 참여 버튼은 #b34a46
  • 상단 ‘함께 만드는 앨범’ 소제목 — 헤더에 브랜드가 이미 있다
  • ‘어떻게 불러드릴까요?’ → 참여자명

지키는 것

  • 14px 미만 없음. 누르는 영역 44px 이상 (입력·참여 56, 카카오 52)
  • 애니메이션·그림자·장식 없음. 카드는 배경 색차로만 띄운다
  • 표지 사진은 전폭이 아닌 196×140 상자에 가운데 정렬하고 모서리 8px. 전폭이면 세로·정사각 사진의 양옆이 크게 재단된다. 구현 시 object-fit:cover
  • 가입 없이 참여 버튼 → 바로 앨범으로
  • AI·곧·준비 중·기능 목록 없음
  • 맨 위 점선 줄(기존 헤더 53px)은 자리 표시 — 구현하지 않는다
