## 배포 전 확인

- [ ] 변경 범위가 MVP 문서·코드 범위와 일치한다.
- [ ] `BUG_LOG.md`에 P0/P1 오픈 이슈가 없다.
- [ ] 프로덕션용 환경 변수가 설정되어 있다.
- [ ] Supabase 인증 설정과 Magic Link 리디렉션 URL이 대상 URL과 일치한다.
- [ ] 카카오 JavaScript 키가 대상 도메인에서 사용할 수 있도록 설정되어 있다.
- [ ] 사진 저장소와 PDF 저장소에 필요한 접근 권한이 설정되어 있다.
- [ ] 비밀값, 서비스 키, 개인 이메일이 클라이언트 코드나 문서에 포함되지 않았다.

## 필수 스모크 테스트

- [ ] 비회원으로 사진을 올려 앨범을 하나 생성했다.
- [ ] 생성한 앨범을 새 탭과 시크릿 창에서 열었다.
- [ ] 공유 링크에서 게스트 기억을 하나 남겼다.
- [ ] 비회원 앨범을 이메일 Magic Link로 내 계정에 보관했다.
- [ ] 로그인 후 내 앨범 목록에서 앨범을 열었다.
- [ ] PDF를 다운로드하고 표지·사진·마지막 페이지를 확인했다.
- [ ] 모바일 카카오톡에서 카카오 공유 또는 대체 공유 흐름을 확인했다.

## 배포 확인

- [ ] 빌드가 성공했다.
- [ ] 배포가 성공했고 대상 URL이 최신 배포를 가리킨다.
- [ ] 대상 URL의 커밋이 릴리스 커밋과 일치한다.
- [ ] 프로덕션 URL에서 필수 스모크 테스트를 다시 완료했다.
- [ ] 브라우저 콘솔에 반복되는 치명적 오류가 없다.
- [ ] 업로드, 앨범 조회, 인증, PDF 요청에서 5xx 오류가 없다.

## 롤백 준비

- [ ] 직전 정상 배포의 커밋과 배포 URL을 기록했다.
- [ ] 롤백 담당자와 연락 방법을 확인했다.
- [ ] 앨범 데이터 및 업로드 사진을 삭제하지 않는 롤백 절차임을 확인했다.

- [ ] 보류: 미통과 항목과 이슈 번호 기록
