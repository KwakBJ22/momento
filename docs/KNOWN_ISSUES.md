# Momento MVP 알려진 제약 사항

> 이 문서는 현재 MVP의 의도된 범위와 테스트 시 주의할 제약을 기록한다. 재현 가능한 결함은 `BUG_LOG.md`에 별도로 등록한다.

## 현재 제약

| 영역 | 제약 | 사용자 영향 | QA 확인 방법 |
| --- | --- | --- | --- |
| 앨범 생성 | 사진 업로드와 앨범 생성은 네트워크 상태 및 사진 수·용량에 따라 시간이 걸릴 수 있다. | 느린 네트워크에서 완료까지 대기 시간이 길 수 있다. | 느린 네트워크와 큰 사진으로 생성 완료·오류 안내를 확인한다. |
| 비회원(게스트) 앨범 | 로그인 없이 앨범을 만들고 볼 수 있다. 게스트 앨범은 **그 브라우저의 게스트 세션 토큰**(localStorage `momento-guest-album-token:<albumId>`)에 묶이며, 접근·수정 권한은 백엔드가 그 토큰으로만 검증한다. 세션 만료는 **7일**(`guest_album_sessions.expires_at` 기본값, migration `20260803130000`). 만료 후에도 claim 안 된 채 버려진 게스트 앨범은 운영 스크립트(`scripts/cleanup_guest_albums.py`, 마지막 만료+7일 지난 것만, dry-run 기본)로 정리한다(OPERATIONS.md 참고). | 브라우저 데이터를 지우거나 다른 기기·브라우저에서는 저장(claim) 전 게스트 앨범을 찾을 수 없다. 7일이 지나면 저장할 수 없고, 이후 정리 대상이 된다. | 게스트로 생성→같은 브라우저에서 조회·수정, "내 앨범으로 저장하기"→로그인→claim 후 소유 이전을 확인한다. 다른 브라우저/토큰 없이는 접근이 거부(403)되는지 확인한다. |
| Magic Link | 이메일 수신과 링크 열기는 메일 서비스 및 기기 간 브라우저 상태에 영향을 받는다. | 수신 지연, 스팸함 분류, 다른 브라우저에서의 리디렉션 문제가 발생할 수 있다. | 실제 메일함·스팸함과 모바일/데스크톱 링크 열기를 확인한다. |
| PDF | PDF는 브라우저에서 앨범을 렌더링한 뒤 생성한다. | 사진이 많거나 기기 성능이 낮으면 생성 시간이 길어질 수 있다. | 여러 장의 사진으로 페이지 구성과 다운로드 완료를 확인한다. |
| 업로드 경로(중요) | 프로덕션에서 `VITE_API_BASE_URL` 이 비어 있으면 업로드가 Vercel 서버리스 프록시(`frontend/api/[...path].ts`)를 타는데, 이 프록시는 **요청 본문 4.5MB 플랫폼 한도**가 있다. | **사진 여러 장(대략 5장 이상, ~4.5MB 초과) 앨범 생성이 전부 실패**한다("업로드에 실패했습니다. 네트워크 연결을 확인해주세요."). 실패 시도는 Railway HTTP 로그에 도달 기록조차 없다(프록시에서 막힘). 근거: 성공한 앨범 최대치가 6장 4.91MB이고 그 이상은 전무. | **해결: Vercel 환경변수 `VITE_API_BASE_URL` 를 Railway 공개 도메인으로 지정**해 업로드가 프록시를 우회해 백엔드에 직접 붙게 한다(사용자가 Vercel 콘솔에서 설정 후 재배포). 배포 후 `npm run test:smoke`(프로덕션 대상)의 API_BASE 항목이 이 설정 누락을 잡는다. 프록시 코드는 공유 링크 등 작은 요청에 계속 사용한다. |
| 인쇄 크기 | 업로드 시 사진의 긴 변을 2560px로 축소한다(의도된 정책, `optimizeImageFile.ts` `MAX_EDGE`). | **A4를 초과하는 대형 인쇄는 화질이 부족할 수 있다.** A4 300DPI까지는 커버한다. | A4 인쇄물 기준으로 화질을 확인한다. 대형 인쇄용 고화질 PDF는 출시 후 서버 렌더링으로 별도 처리 예정. |
| 카카오 공유 | 카카오 공유는 카카오 JavaScript 키와 카카오 SDK 사용 가능 여부에 의존한다. | 키/SDK가 없거나 지원하지 않는 브라우저에서는 카카오 공유를 사용할 수 없다. | 카카오톡 인앱에서 공유를 확인하고, 일반 브라우저의 대체 공유를 확인한다. |
| 공유 앨범 | 공유 링크를 받은 사람은 앨범을 조회하고 기억을 남길 수 있다. | 링크가 전달되면 의도하지 않은 사람도 접근할 수 있다. | 공유 대상을 제한해 전달하고, 테스트 링크는 테스트 후 폐기한다. |
| 동영상 미지원 | **백엔드는 이미 동영상을 받을 수 있으나**(media_upload_service, album_media, upload_album media 저장, 삭제 정리까지), 프런트에서 걸러 앨범에 담지 않는다. **개별 업로드가 전제**다: 휴대폰 영상 10초가 10~30MB인데 총량 가드 40MB이고 브라우저에서 압축할 수단이 없다(사진과 달리). 지금은 조용히 사라지지 않고 "동영상 N개는 아직 앨범에 담을 수 없어요"로 안내하며, 시도 건수를 `video_dropped`(metadata `video_count`)로 계측한다(**앨범을 실제로 만든 경우만** 집계 — 업로드 요청에 실어 보내므로). | 사용자가 고른 동영상은 앨범에 담기지 않는다. 안내는 표시된다. | 사진+동영상 혼합 선택 시 안내 문구와 사진만 담기는지 확인한다. |

## MVP 범위 밖

- 앨범의 세밀한 공동 편집 및 참여자별 권한 관리
- 비회원 앨범을 여러 기기에서 자동 복구하는 계정 없는 동기화
- PDF의 인쇄 업체별 색상·여백 보정
- 카카오 외 메신저별 전용 공유 카드 최적화

## 운영 시 확인할 항목

- 과거 발급된 `/invite/<token>` 링크는 이메일 미동의 사용자에게 400을 반환한다. 신규 발급 경로(AlbumMembersPanel/FamilyManagement)가 App에 라우팅되지 않아 실사용 영향은 없다. 참여는 공유 링크(guest_id 기반)로 대체됐다.
- Magic Link 요청·인증 실패가 증가하면 인증 설정과 리디렉션 URL을 우선 점검한다.
- 앨범 생성 또는 PDF 실패가 증가하면 업로드 크기, 네트워크, 브라우저 오류를 함께 확인한다.
- 카카오 공유 문의는 사용 기기, 카카오톡 인앱 여부, 공유 링크 열림 여부를 먼저 확인한다.
