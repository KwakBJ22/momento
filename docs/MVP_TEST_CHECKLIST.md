# Momento MVP 테스트 체크리스트

> 대상: Momento 웹 MVP
> 목적: 릴리스 전 핵심 사용자 흐름을 빠르게 점검한다.

## 테스트 준비

- 최신 배포 환경과 로컬 환경에서 각각 확인한다.
- 사진 1장, 여러 장(세로/가로 혼합), 큰 파일을 준비한다.
- 새 브라우저 프로필 또는 시크릿 창으로 비회원 흐름을 확인한다.
- Magic Link 수신이 가능한 이메일 계정을 준비한다.
- 카카오톡 앱이 설치된 모바일 기기와 일반 모바일 브라우저를 준비한다.

## 핵심 흐름

### 1. 비회원 앨범 생성

- [ ] 로그인하지 않은 상태에서 앨범 만들기를 시작할 수 있다.
- [ ] 사진을 선택하고 앨범 생성에 필요한 정보를 입력할 수 있다.
- [ ] 사진 업로드 후 앨범 생성 진행 상태가 사용자에게 표시된다.
- [ ] 생성 완료 후 표지, 사진, 스토리/에필로그가 포함된 앨범을 볼 수 있다.
- [ ] 새로고침 후에도 현재 브라우저에서 방금 만든 앨범을 다시 열 수 있다.
- [ ] 사진이 1장일 때와 여러 장일 때 모두 앨범이 깨지지 않는다.
- [ ] 가로·세로 사진이 비정상적으로 늘어나거나 잘리지 않는다.
- [ ] 업로드 실패 또는 생성 실패 시 이해할 수 있는 오류 안내와 재시도 방법이 제공된다.

### 2. 공유 및 게스트 참여

- [ ] 앨범에서 공유 링크를 만들거나 복사할 수 있다.
- [ ] 공유 링크를 시크릿 창에서 열면 앨범을 볼 수 있다.
- [ ] 공유 페이지의 제목·설명·대표 이미지가 정상적으로 표시된다.
- [ ] 게스트가 이름과 기억을 입력해 남길 수 있다.
- [ ] 필수 입력값 없이 기억을 남기려 하면 저장되지 않는다.
- [ ] 저장한 게스트 기억이 앨범 소유자 화면에서 확인된다.
- [ ] 게스트 반응 버튼을 눌러도 화면이 중단되지 않는다.
- [ ] 잘못되었거나 만료된 공유 링크는 안전한 오류 화면을 표시한다.

### 3. 내 앨범 보관 및 Magic Link

- [ ] 비회원이 만든 앨범에서 이메일로 보관을 시작할 수 있다.
- [ ] 이메일을 입력하면 Magic Link 안내가 표시된다.
- [ ] 수신한 Magic Link를 열면 동일 브라우저와 새 브라우저 모두에서 로그인 흐름이 완료된다.
- [ ] 로그인 후 방금 만든 비회원 앨범이 내 앨범에 연결된다.
- [ ] 다른 사용자의 계정으로는 비회원 앨범을 보관할 수 없다.
- [ ] 게스트가 남긴 기억을 보관하려고 로그인한 경우, 해당 기억이 본인 계정에 연결된다.
- [ ] 내 앨범 목록에 제목, 대표 이미지, 생성일, 사진 수가 표시된다.
- [ ] 내 앨범 목록의 카드에서 해당 앨범으로 이동할 수 있다.
- [ ] 로그아웃/재로그인 후에도 보관한 앨범이 목록에 남아 있다.

### 4. PDF 내보내기

- [ ] 앨범에서 PDF 다운로드를 시작할 수 있다.
- [ ] 첫 다운로드 시 생성된 PDF 파일이 내려받아진다.
- [ ] 같은 앨범 버전을 다시 다운로드해도 정상적으로 내려받아진다.
- [ ] PDF 표지, 사진, 스토리/에필로그가 화면 앨범과 일치한다.
- [ ] PDF가 A4 세로 형식으로 열리고 빈 페이지 또는 겹침이 없다.
- [ ] 사진이 많은 앨범에서도 PDF 생성이 완료되거나 실패 안내가 표시된다.

### 5. 카카오 공유

- [ ] 카카오 JavaScript 키가 설정된 환경에서 카카오 공유 버튼이 표시된다.
- [ ] 카카오톡 앱에서 공유 시 앨범 제목, 설명, 대표 이미지, 링크가 포함된다.
- [ ] 공유 메시지의 앨범 보기 버튼이 공유 앨범으로 이동한다.
- [ ] 카카오 SDK를 사용할 수 없는 환경에서는 링크 복사 등 대체 방법을 안내한다.
- [ ] 일반 브라우저 공유 또는 링크 복사도 공유 URL을 정확히 전달한다.

## 회귀 점검

- [ ] 모바일 화면(360px 이상)에서 생성, 조회, 공유, 보관 버튼을 모두 누를 수 있다.
- [ ] Chrome, Safari(iOS), 카카오톡 인앱 브라우저에서 핵심 흐름을 확인한다.
- [ ] 새로고침, 뒤로가기, 여러 탭 사용 중에도 앨범 접근 권한이 의도치 않게 변경되지 않는다.
- [ ] 네트워크가 느린 환경에서 중복 앨범 생성 또는 중복 기억 저장이 발생하지 않는다.
- [ ] 사용자에게 API 키, 세션 토큰, 내부 오류 정보가 노출되지 않는다.
