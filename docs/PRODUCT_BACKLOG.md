# Momento 제품 백로그

이 문서는 **무엇을 만들지와 현재 구현 상태**를 관리한다. 실제 배포 설정의 완료 여부는 `LAUNCH_CHECKLIST.md`, OAuth 설정 방법은 `SOCIAL_AUTH_SETUP.md`에서 관리한다.

## 상태와 우선순위

| 상태 | 의미 |
| --- | --- |
| 완료 | 코드와 자동 검증이 있는 기능 |
| 출시 전 | MVP 공개 전 필요한 기능 또는 정책 |
| 계획 | 출시 후 우선순위가 정해진 기능 |
| 보류 | 제품·비용·법무 결정 후 진행할 기능 |

| 우선순위 | 출시 대상 |
| --- | --- |
| P0 | MVP 출시 차단 |
| P1 | 첫 공개 이후 빠르게 제공 |
| P2 | 성장 단계 |

## 앨범

| 항목 | 상태 | 우선순위 | 출시 대상 | 비고 |
| --- | --- | --- | --- | --- |
| 비로그인(게스트) 앨범 생성 | 완료 | P0 | MVP | 로그인 없이 생성·확인. 앨범은 `owner_id=NULL`로 저장되고 브라우저의 게스트 세션 토큰(`guest_album_sessions.token_hash`)에 묶인다. 그 토큰으로만 접근·수정(백엔드 검증). 세션 만료 24h. |
| 게스트 앨범 저장(claim) | 완료 | P0 | MVP | "내 앨범으로 저장하기" → 로그인 → `claim_guest_album_ownership` RPC로 `owner_id`/`created_by`/`family_id` 설정, 세션 `claimed`. 같은 사용자 재시도 idempotent. |
| 로그인 사용자 앨범 생성 | 완료 | P0 | MVP | `owner_id`는 Auth user id (기존 흐름 유지) |
| 사진 최대 30장 생성 | 완료 | P0 | MVP | 이미지 분석 기본 비활성 |
| 사진 100장 확대 | 계획 | P1 | 출시 후 | 업로드·생성·PDF 비용 검토 필요 |
| 개별(장별) 업로드 · 진행 상태와 재시도 | 계획 | P1 | 출시 후 | 실패 파일 단위 재시도. LTE 30장 성공으로 출시 후 과제 확정. 아래 동영상 지원의 전제. |
| └ 동영상 지원 | 보류 | P2 | 출시 후 | **개별 업로드가 전제**(위). 백엔드는 준비됨(media_upload_service·album_media·upload_album media 저장·삭제 정리). 현재 프런트 필터가 막고 조용히 사라지지 않게 안내 + `video_dropped`(metadata `video_count`)로 수요 계측. 총량 40MB·브라우저 압축 부재가 제약. |
| 제목·사진 코멘트·에필로그 수정 | 완료 | P0 | MVP | 소유자 권한 |
| 대표사진 선택·교체 | 완료 | P0 | MVP | stable media id 기준 |
| Living Album 페이지 추가·새 에디션 | 완료 | P1 | MVP | 참여 항목 반영 |
