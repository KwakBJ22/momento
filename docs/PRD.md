# Momento MVP PRD

## 1. 목표
30일 안에 카카오톡에서 유입된 사용자가 사진으로 추억 앨범을 만들고, 가족·친구를 초대해 함께 완성하는 경험을 검증한다.

## 2. 핵심 가설
1. 사용자는 사진 5장 이상을 올려 AI 이야기를 생성한다.
2. 완성된 앨범을 다른 사람에게 공유한다.
3. 초대받은 사람이 사진·댓글을 추가한다.
4. 사용자는 7일 안에 다시 방문한다.

## 3. 핵심 사용자 흐름
랜딩 → 관계 선택 → 사진 업로드 → 날짜/장소/메모 → AI 이야기 생성 → 앨범 저장 → 공유/초대 → 참여자 사진·댓글 추가 → 이야기 재생성

## 4. MVP 기능

### 4.1 앨범 생성
- 관계: 가족, 친구, 연인, 동료, 기타
- 제목은 AI 생성 후 수정 가능
- 날짜 필수
- 장소 선택
- 메모 선택
- 사진 1~20장
- 지원 형식: JPG, PNG, WEBP
- 사진당 최대 10MB

### 4.2 AI 이야기 생성
입력:
- 관계
- 날짜
- 장소
- 사용자 메모
- 사진별 설명 또는 이미지 분석 결과

출력:
- 제목
- 한 줄 요약
- 본문 600~1,200자
- 사실을 모르면 추측하지 않음

### 4.3 앨범 보기
- 커버 사진
- 제목, 날짜, 장소
- 이야기
- 사진 목록
- 참여자
- 댓글
- 공유 버튼

### 4.4 공유 및 협업
- 공개되지 않는 초대 링크 생성
- 링크 접속 후 이름 입력
- 참여자는 사진 추가 가능
- 참여자는 댓글 작성 가능
- 소유자만 AI 이야기 재생성 가능

### 4.5 관리자
- 일별 가입자
- 앨범 생성 수
- 앨범 완료율
- 공유율
- 초대 전환율
- 협업 앨범 비율
- 7일 재방문율

## 5. 권한
- owner: 수정, 삭제, 공유, 초대, 재생성
- contributor: 사진 추가, 댓글 작성
- viewer: 보기만 가능
- admin: 전체 통계 확인

## 6. 완료 기준
- 사진 업로드부터 앨범 생성까지 모바일에서 3분 이내
- 앨범 생성 실패 시 재시도 가능
- 공유 링크로 비로그인 참여 가능
- 모든 핵심 행동은 events 테이블에 기록

## 7. MVP 제외
- 결제
- PDF 출력
- 음성 대화
- AI 친구
- 네이티브 앱
- 공개 피드
- 고급 사진 편집
