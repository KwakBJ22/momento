# Momento MVP QA 가이드

## 목적과 원칙

Momento MVP QA는 사용자가 로그인 여부와 관계없이 사진을 추억 앨범으로 만들고, 다른 사람과 나누고, 필요할 때 다시 찾을 수 있는지를 확인한다. 구현 방식보다 실제 사용자 흐름을 우선한다.

테스트 중 발견한 문제는 `BUG_LOG.md`에 재현 절차와 환경을 함께 기록한다. 앨범 생성 실패, 권한 오류, 데이터 노출, 보관 불가는 즉시 P0 또는 P1 여부를 판단한다.

## 권장 테스트 계정과 데이터

| 구분 | 용도 |
| --- | --- |
| 비회원 브라우저 | 앨범 생성, 공유 링크 접근, 게스트 기억 작성 |
| 계정 A | 비회원이 만든 앨범을 보관하는 소유자 계정 |
| 계정 B | 다른 계정으로 앨범 보관/접근이 차단되는지 확인 |
| 게스트 데이터 | 이름과 300자 이내 기억, 이모지 포함 텍스트 |
| 사진 데이터 | 1장, 5장 이상, 가로/세로, 고해상도 사진 |

실사용자의 이메일·사진·공유 링크는 QA 기록에 남기지 않는다.

## 테스트 시나리오

### 비회원에서 앨범 생성까지

1. 시크릿 창에서 서비스 첫 화면을 연다.
2. 사진을 선택하고 앨범 생성 흐름을 완료한다.
3. 생성 화면에서 사진, 제목, 스토리와 앨범 레이아웃을 확인한다.
4. 새로고침 후에도 앨범을 다시 볼 수 있는지 확인한다.

확인 포인트: 업로드 중 이탈 방지, 실패 안내, 이미지 비율, 중복 생성 여부.

### 공유 링크와 게스트 참여

1. 생성한 앨범의 공유 링크를 복사한다.
2. 시크릿 창 또는 다른 기기에서 링크를 연다.
3. 게스트 이름과 기억을 입력해 저장한다.
4. 앨범 소유자 화면에서 추가된 기억을 확인한다.

확인 포인트: 링크 접근성, 입력값 검증, 저장 성공 안내, 잘못된 토큰의 오류 처리.

### Magic Link와 내 앨범 보관

1. 비회원 앨범에서 보관하기를 선택한다.
2. 이메일 주소로 Magic Link를 요청한다.
3. 이메일의 링크를 열어 로그인한다.
4. 내 앨범 화면에서 방금 만든 앨범을 확인하고 열어 본다.
5. 계정 B로 로그인해 같은 비회원 앨범을 보관하려고 시도한다.

확인 포인트: 리디렉션 후 로그인 완료, 앨범 연결 유지, 다른 계정의 보관 차단, 기존 게스트 기억 연결 유지.

### PDF와 카카오 공유

1. 사진이 여러 장인 앨범에서 PDF 다운로드를 실행한다.
2. 내려받은 파일을 열어 모든 페이지와 사진 품질을 확인한다.
3. 모바일 카카오톡에서 카카오 공유를 실행한다.
4. 전송 화면의 제목, 설명, 썸네일, 앨범 링크를 확인한다.
5. 카카오 SDK를 쓸 수 없는 브라우저에서 대체 공유 흐름을 확인한다.

확인 포인트: PDF 생성 대기 시간, 페이지 분리/겹침, 링크 이동, SDK 미설정 시 안내.

## 완료 기준

- `MVP_TEST_CHECKLIST.md`의 핵심 흐름이 모두 통과한다.
- P0/P1 문제는 수정 및 재검증되었거나 릴리스가 보류된다.
- 실패한 항목은 환경, 재현 절차, 화면 캡처를 포함해 버그 로그에 남긴다.
