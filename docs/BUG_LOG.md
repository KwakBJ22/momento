# Momento MVP 버그 로그

> 발견된 문제를 재현 가능하게 기록하고, 릴리스 판단의 근거로 사용한다.

## 상태 정의

| 상태 | 의미 |
| --- | --- |
| 신규 | 재현 확인 전 또는 방금 등록된 문제 |
| 확인됨 | 재현 절차와 영향 범위를 확인한 문제 |
| 진행 중 | 수정 작업 중인 문제 |
| 수정됨 | 수정 후 검증 대기 |
| 종료 | 대상 환경에서 재검증 완료 |
| 보류 | MVP 범위 밖이거나 릴리스 후 처리할 문제 |

## 심각도 기준

| 심각도 | 기준 |
| --- | --- |
| P0 | 앨범 생성, 조회, 보관이 불가능하거나 데이터/권한 문제가 있는 경우 |
| P1 | 핵심 흐름을 우회 없이 완료할 수 없는 경우 |
| P2 | 일부 환경 또는 조건에서 핵심 경험이 저하되는 경우 |
| P3 | 문구, 정렬, 비핵심 UI 등 경미한 문제 |

## 등록 양식

```md
### BUG-000

- 상태: 신규
- 심각도: P0 / P1 / P2 / P3
- 발견일:
- 발견 환경: 운영/미리보기/로컬, 브라우저·기기
- 관련 기능: 앨범 생성 / 게스트 참여 / 보관 / Magic Link / PDF / 카카오 공유
- 재현 절차:
  1.
  2.
  3.
- 기대 결과:
- 실제 결과:
- 첨부: 화면 캡처, 콘솔 오류, 요청 ID (민감 정보 제외)
- 담당:
- 수정/검증 메모:
```

## 오픈 이슈

현재 등록된 오픈 이슈 없음.

새 이슈는 위 양식을 복사해 이 섹션에 추가한다. P0 또는 P1은 `RELEASE_CHECKLIST.md`의 릴리스 차단 항목에 함께 반영한다.
